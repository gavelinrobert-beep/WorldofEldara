# Thornveil Scene Assets

This folder contains Blender-authored scene blockouts and exports for the 3D prototype.

Current files:

- `ThornveilEnclave_Blockout.blend` - editable Blender source scene.
- `thornveil-enclave-blockout.glb` - exported scene blockout for importer/runtime experiments.
- `thornveil-enclave-blockout.placements.json` - object placement metadata generated from Blender.

The blockout is intentionally modular. The final runtime path should prefer reusable assets plus placement data over a single large scene mesh.
