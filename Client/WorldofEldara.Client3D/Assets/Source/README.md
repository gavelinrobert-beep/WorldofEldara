# Source Assets

Editable Blender sources for generated prototype assets.

- `ThornveilTerrainKit.blend` - first low-poly terrain kit for Thornveil Enclave. Exports six repeatable GLB tiles into `../Models/Terrain/`.
- `ThornveilLandmarkKit.blend` - first low-poly landmark kit. Exports treehouse, root bridge/stairs, cyan crystal cluster, and great root arch GLBs into `../Models/Landmarks/`.

Keep source files here rather than under `Models/` so runtime builds copy only game-ready assets.
