# Starter Zone 01: Thornveil Enclave

Thornveil Enclave is the Sylvaen starter zone and the current seat of the Verdant Circle. It is an ancient forest where the Worldroot presence is stronger than anywhere else in the known world: a living archive, a sacred immune system, and a home grown from memory.

This document is the gameplay-facing starter-zone brief. The deeper art and world bible lives in [thornveil-enclave.md](./thornveil-enclave.md).

## Core Feeling

Thornveil should feel warm, colorful, mystical, and readable. The first impression is safety: lush moss, exaggerated green leaves, gold-brown wood, warm stone, cyan Worldroot crystals, friendly NPCs, small creatures, and clear paths.

The danger should enter gradually. At first the player gathers seeds, listens to roots, and speaks with Memory Keepers. Later the forest repeats itself incorrectly: animals return after death, paths remember events that never happened, and Worldroot memories begin to bleed.

## First Minute

The player starts on a soft moss and stone path at the edge of Heartbough Glade. Ahead is a living village of tree platforms, green roofs, hanging lanterns, crystal-lit roots, and root bridges. A Memory Keeper waits near a runestone. A small Wildroot Fawn crosses the road. In the distance, a cyan Worldroot heart pulses inside a great tree.

Everything says: you are home.

Then the first memory-registration interaction fails slightly. The forest remembers the place. It remembers the choice. It does not quite remember the player.

## Gameplay Goals

- Move through a readable, welcoming grove.
- Meet the first Memory Keeper, Root Guardian, Elder, and class/training NPCs.
- Learn movement, targeting, combat, interaction, quest accept/turn-in, and quest tracking.
- Complete talk, interact, kill, collect, and return objectives.
- See the first signs that Worldroot memory is unstable.
- Build toward the first lower-root mini-dungeon or enclosed encounter space.

## Zone Flow

1. Listener's Ring: calm tutorial clearing where the player learns to listen to the Worldroot.
2. Heartbough Glade: central hub with vendors, trainers, Memory Keepers, Root Guardians, and crafting anchors.
3. Whisperroot Paths: first outdoor objective paths with root bridges, low tunnels, crystals, and simple enemies.
4. Mossglass Pools: reflective wetland where Memory Echoes replay broken scenes from lost civilizations.
5. The Green Scar: darker edge of the starter zone, where memory corruption, Void rifts, and corrupted beasts appear.
6. Seedvault Veyr: first mini-dungeon threshold beneath the old roots.

## Visual Anchors

- Massive readable tree trunks.
- Treehouses with green roofs and gold wood inlays.
- Living root bridges and broad stairs.
- Verdant Circle banners on wood/root poles.
- Cyan and turquoise Worldroot crystals.
- Mossy stone paths with clear edges.
- Memory Echoes as short blue shimmering figures.
- Fawns, deer, and small forest creatures near safe areas.
- Purple/black-green corruption only near The Green Scar.

## Key Places

### Heartbough Glade

The central hub. A large glade built around a heart-tree whose roots form plaza edges, stairs, natural walls, and terraces. It should feel like the player's first home: warm light, open space, friendly NPCs, wandering animals, and clear paths outward.

### Listener's Ring

A ceremonial training clearing. Young Sylvaen learn to hear the Green Memory here. Use small runestones, memory roots, tutorial interactions, and gentle lighting.

### Whisperroot Paths

The first adventure paths outside the hub. Roots form low bridges and tunnels. Small crystals guide the player toward objectives. Early enemies live here: thornlings, corrupted small beasts, and echo-wolves.

### Mossglass Pools

A reflective wetland where the water shows earlier events. Blue Memory Echoes stand near or inside pools, replaying fragments from lost people and lost civilizations. This is the first clear sign that memory is not stable.

### The Green Scar

The darker edge of Thornveil. Colors become muted, bark is cracked, roots twist, and purple-green wounds break the ground. This area introduces memory-corrupted beasts, High Elf scouts, and minor Void rifts.

## Quest Arc

- `A Name for a Season`
- `The Listening Bark`
- `Sap That Remembers`
- `The Hare That Died Twice`
- `The Scar That Learns`
- `The Door Under the Roots`
- `Below the Listening Door`
- repeatable support quest: `First Pruning`

The arc starts with learning and reverence, then moves into uncertainty, then finally reveals that the Worldroot does not merely preserve memory. It carries memory as weight, and the weight is beginning to bleed.

## First Mini-Dungeon Hook

Seedvault Veyr has an open-world threshold area, `Seedvault Antechamber`, used as a prototype mini-dungeon space before true instancing exists.

- trash: Ward-Eaten Rootlings
- mini-boss: Sealgnawer Matron
- objective object: Veyr Memory Core
- purpose: test denser combat, boss targeting, quest chaining, and reward pacing inside one contained sub-area

## Current 3D Prototype Requirements

- Keep the safe spawn readable and away from hostile aggro.
- Keep the main path clear from spawn to Heartbough Glade.
- Use fewer, larger landmarks instead of many tiny props.
- Use cyan crystals as navigation and quest readability accents.
- Keep corruption visually contained to The Green Scar until the quest arc escalates.
- Replace temporary C# proxy meshes with imported or generated asset meshes as the rendering path matures.
